# طباعة الصور بألوانها الحقيقية — HP Smart Tank 580

برنامج يطبع صور الموبايل والكاميرا بأي صيغة بنفس ألوانها وتفاصيلها كما ظهرت عند التصوير.
الوضع الأساسي: تختار الصورة وتضغط **اطبع**.

## ليه الصور كانت بتطلع وحشة؟

| السبب | اللي البرنامج بيعمله |
|---|---|
| الموبايل يحفظ الصور بألوان **Display P3** (أوسع من sRGB). الطابعة تقرأ أي صورة على أنها **sRGB**، فالألوان تطلع باهتة ومزاحة. | يقرأ بروفايل الألوان المضمّن في الصورة (ICC أو nclx) ويحوّل الألوان رياضياً إلى sRGB. التحويل مُختبَر مقابل LittleCMS بفرق أقصاه مستويين من 255. |
| الألوان المشبعة جداً (ورد، سماء، ملابس) خارج قدرة الطابعة، فتتحوّل لبقع مسطّحة بلا تفاصيل. | **ضغط لوني ناعم (Gamut compression)** يحافظ على الإضاءة ودرجة اللون (Hue)، ويدخل الألوان الزائدة للنطاق تدريجياً، فتفضل التدرجات والتفاصيل ظاهرة. |
| صيغة HEIC غير مدعومة في برامج كتير، والتحويل لـ JPG يضيّع الألوان أو يحوّلها لـ 8-bit بشكل سيئ. | يفتح HEIC مباشرة بعمق 10-bit، ويفتح RAW بعمق 16-bit، ويعالج كل حاجة بدقة عالية لحد الخطوة الأخيرة (مع Dithering يمنع التدرجات المتقطعة في السماء). |
| الشاشة تُضيء والورق يعكس الضوء، فالمطبوع يبان أغمق. | **تعويض إضاءة خفيف** للدرجات المتوسطة. الأسود يفضل أسود والأبيض أبيض. تقدر تتحكم فيه أو تلغيه. |
| إعدادات الطابعة غلط (ورق عادي، جودة عادية، تصغير أو قص غير مقصود). | يرسل للطابعة: نوع ورق صور، أعلى جودة، وضع صور، بدون حواف، ومقاس الصفحة بالظبط 1:1. |
| دقة غير مناسبة ونعومة بعد التصغير. | تصغير Lanczos لدقة الطابعة (300 أو 600 تلقائياً)، ثم زيادة حدّة مناسبة للطباعة. |

## التشغيل

1. ثبّت **Python 3.10 أو أحدث** من python.org. على ويندوز علّم على خيار *Add to PATH*.
2. ويندوز: دبل كليك على `start-windows.bat`.
   ماك/لينكس: شغّل `start-mac-linux.command`.
   أول مرة بيثبّت المكتبات لوحده.
3. البرنامج يفتح في المتصفح. اختار الطابعة، واسحب الصور، واضغط **اطبع**.

### توصيل الطابعة

- **Wi-Fi** (الأفضل): البرنامج يلاقي الطابعة لوحده. لو ما ظهرتش، اكتب عنوان الـ IP بتاعها. تلاقيه من زرار Wi-Fi في الطابعة أو من تطبيق HP Smart، مثلاً `192.168.1.50`.
  البرنامج يكلّم الطابعة مباشرة ببروتوكول IPP، نفس بروتوكول AirPrint، فمش محتاج تعريف. ويقرأ منها المقاسات وأنواع الورق المدعومة وهل المقاس يقبل الطباعة بدون حواف ومستوى الحبر.
- **USB على ويندوز**: اختار الطابعة من القائمة (الاسم المتسجّل في ويندوز). البرنامج هنا يطبع من خلال تعريف HP.

## الإعدادات

**أساسية:** مقاس الورق (4×6، 5×7، A4، Letter، A5، A6، 8×10، L، Hagaki، أو مقاس مخصص)، ونوع الورق (لامع HP Advanced Photo / مطفي / بروشور / عادي)، والجودة، وعدد النسخ، وطباعة بدون حواف، وملء الورقة مع قص أو إظهار الصورة كاملة، وعدد الصور في الصفحة (1، 2، 4، 6، 9، 12)، وأبيض وأسود (بكل الأحبار لصورة فوتوغرافية محايدة، أو بالحبر الأسود فقط).

**متقدمة:** تعويض الإضاءة، والتشبع، والحدّة، ودقة الإرسال (300/600)، وطريقة معالجة الألوان خارج النطاق، ودرج الورق، والهوامش، والتدوير التلقائي. وكمان حفظ **PDF جاهز للطباعة** لو حابب تطبع من برنامج تاني أو من تطبيق HP Smart.

## سطر الأوامر (اختياري)

```bash
python -m photoprint printers                         # البحث عن الطابعات
python -m photoprint info 192.168.1.50                # كل إمكانيات الطابعة + الحبر
python -m photoprint print -p 192.168.1.50 IMG_1234.HEIC IMG_1235.HEIC
python -m photoprint print -p 192.168.1.50 --paper A4 --layout 4 --border --media matte *.jpg
python -m photoprint convert --paper 4x6 -o print-ready/ *.HEIC   # ملفات JPG جاهزة للطباعة
python -m photoprint jobs 192.168.1.50 ; python -m photoprint cancel 192.168.1.50 17
```

## نصايح لأفضل نتيجة

- استخدم **ورق صور حقيقي** واختار نوعه صح. ده أكبر فرق بعد تصحيح الألوان.
- لو المطبوع لسه أغمق من الشاشة، ارفع "تعويض الإضاءة" لـ 1.5. ولو أفتح، نزّله لـ 0.5.
- خلي سطوع الموبايل متوسط وقت المقارنة. السطوع العالي جداً يخلّي أي طباعة تبان غامقة.
- صور **HDR** الحديثة يطبع البرنامج نسختها العادية (SDR) كما تظهر في معظم البرامج، ولو الصورة HDR كاملة (PQ/HLG) يحوّلها بتدرّج ناعم للإضاءات العالية.

```bash
pip install pytest && python -m pytest tests -q
```

الاختبارات بتغطي:
- دقة تحويل P3 إلى sRGB مقارنة بـ LittleCMS.
- ضغط الألوان وثبات الـ Hue.
- فتح HEIC بعمق 10-bit مع ICC وnclx، وPNG بعمق 16-bit، واتجاه الصورة من EXIF، والشفافية.
- أبعاد الصفحات والتقسيم لأكثر من صورة وصحة ملف PDF.
- إرسال مهمة IPP كاملة لطابعة وهمية تحاكي Smart Tank 580، بما فيها الرجوع لطباعة بحواف لما المقاس ما يدعمش بدون حواف.
